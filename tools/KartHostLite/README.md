# KartHostLite — 卡丁快跑 轻量上位机

从队友 `KartHost`（11.5k 行）里**只搬基础功能**：收帧 → 画波形 → 调参数 → 录 CSV。
不含惯导/路表/标定窗/模拟车端/串口链路。

> 本项目由我与队友 **zjc** 合作完成，他的仓库：
> **[hz303/zjc_kart_cyt4bb7](https://github.com/hz303/zjc_kart_cyt4bb7)**。

## 为什么是这套技术栈

- 队友的 `Protocol.cs` / `FrameParser.cs` / `Link.cs` / `ChannelStore.cs` /
  `CsvRecorder.cs` / `Ui/WavePanel.cs` / `Ui/ParamPanel.cs` 已经解决了最难的两件事：
  **30 FPS 重绘与接收解耦**、**半包/垃圾字节/坏 CRC 下的帧同步**。自己重写等于重踩一遍。
- 因此这些文件是**原样搬过来的**（`namespace KartHost` 保持不变，`RootNamespace` 也设为 `KartHost`，
  一个字符都不用改）。本工程新写的只有 4 个文件：

| 文件 | 作用 |
|---|---|
| `Channels.cs` | ★ 通道表（英文名 / 单位 / 中文简称 / 悬停说明四份平行数组）+ 分图预设 + 实时值格子 ——「通道裁剪」的唯一落点 |
| `Ui/MainForm.cs` | 主窗（左参数 / 中波形分图 / 右实时值+通道显隐 / 底部日志+状态栏） |
| `SelfTest.cs` | 无硬件自检（协议层） |
| `Program.cs` | 入口 + `--selftest` / `--shot-form` / `--shot-demo` |

从队友那份搬来的文件共 10 个（含 `Ui/LampControl.cs` 指示灯）：`Protocol` `FrameParser` `Link`
`ChannelStore` `CsvRecorder` `Ui/Theme` `Ui/Dpi` `Ui/WavePanel` `Ui/ParamPanel` `Ui/LampControl`。

三条**改界面时必须遵守**的规矩（都是踩过的）：

1. **字号写 9pt，不要乘 `Dpi.Scale`**（点值是物理量，GDI+ 自己会放大）。之前写成 `Dpi.Pxf(9f)`，
   150% 下变 13.5pt，整窗大一圈 —— 就是这次改版要修的观感问题。
2. **通道勾选框的字色必须在 `Theme.Apply()` 之后再刷一遍**：它会把所有 `CheckBox.ForeColor`
   统一成 `Theme.Text`，先设就全白，曲线颜色和图例对不上。
3. **多图模式下，勾完默认通道要再套一次分图预设**：勾选会把通道塞进每一张图，
   不补这一步四张图会长得一模一样。

## 运行环境

本机原本**只有 .NET 运行时 8.0.31、没有 SDK**，所以 SDK 装在了工作区内的私有目录（不入系统 PATH）：

```
D:\Project\Code\CYT4BB7\Karting\.tools\dotnet\dotnet.exe   （SDK 9.0.319 + 运行时 9.0.21，约 739 MB）
```

## 怎么运行（exe 在哪）

| 想干什么 | 用哪个 | 说明 |
|---|---|---|
| **双击就能跑** | `dist\KartHostLite.exe` | ★ **自包含单文件（约 113 MB）**，内含 .NET 9 运行时。拷到任何 Win10/11 x64 上直接双击，不需要装 .NET、不需要这个工作区 |
| 开发调试版 | `bin\Debug\net9.0-windows\KartHostLite.exe` | ⚠ **不要双击**。它是 apphost，只会去 `C:\Program Files\dotnet` 找 9.0 运行时，本机只有 8.0.31 → 弹 "You must install or update .NET"。用 `run.bat` 启动 |
| 命令行 / 自检 | `run.bat`、`run.bat --selftest` | 有 `dist` 就跑 `dist`，没有就用私有 SDK 的 `dotnet.exe` 跑 `bin\...\KartHostLite.dll` |

```bat
build.bat            :: Debug 构建（→ bin\Debug\net9.0-windows\）
publish.bat          :: 生成免安装单文件（→ dist\KartHostLite.exe，113 MB）
run.bat              :: 启动界面
run.bat --selftest   :: 无硬件自检（退出码 = 失败项数）
```

`build.bat` / `run.bat` / `publish.bat` 找 dotnet 的顺序：环境变量 `DOTNET` → 私有路径 → PATH 里的 `dotnet`。
换机器时把 `DOTNET` 指过去即可（只有构建/发布需要，跑 `dist` 版不需要）。

⚠ **三个 .bat 必须保持纯 ASCII**：cmd 用 GBK 解码，文件里的中文会让解析错位，
症状是 `'ET_CLI_TELEMETRY_OPTOUT' 不是内部或外部命令` 这种莫名其妙的截断报错。

## 用法（车端是 UDP 客户端）

1. 车端进 Host 页（会自动弹 WiFi 选择界面，连上才开始发）。
2. 本机：填 **本机 UDP 端口 8086** → 点「开始接收」。**不是"去连车"** —— 车端主动发到本机这个端口。
3. 左侧勾选要画的通道；中间波形；右侧参数滑条（滑条一动就下发 `SET_PARAM`）。
4. 「存 Flash / 读 Flash」= `SAVE / LOAD` 命令。
5. 「录制 CSV」= 按 20 ms 周期把勾选通道写盘。

⚠ **防火墙**：首次运行 Windows 会问是否允许网络访问，必须允许，否则收不到 UDP。

## 与车端的协议约定（`Host_Crtl.c` 那一侧）

- 上行 `A5 5A | TYPE | LEN | PAYLOAD | CRC16 | 00 00 80 7F`；CRC16-MODBUS(0xA001)，全小端。
- 遥测载荷 `SEQ(2) + TS(4) + MASK(2) + COUNT(2) + float32×N`；`MASK=0xFFFF` 是「全部有效」哨兵。
- 下行固定 15 字节 `5A A5 | 01 | 08 00 | CMD | ID | VALUE4 | TOKEN2 | CRC2`。
- **通道数由帧内 `COUNT` 自描述**，所以车端改通道数不会让解析失败 —— 只会让**名字错位**。
  ⇒ 改车端 `HOST_CH_*` 时必须同步改 `Channels.cs` 的数组，长度对不上会在日志里红字告警并在波形上挂红条。
- `Channels.cs` 里是**三份平行数组**：`ChannelNames`（英文，CSV 表头/波形图例用）、`ChannelCn`（中文简称，
  右侧勾选列表用，显示宽度控制在 12 个半角单位内）、`ChannelTips`（悬停说明，写取值范围与坑）。
  三份长度由 `--selftest` 强制对齐；中文简称超宽也会被自检拦下来（WinForms 裁字是不报错的）。

## 三个自查手段（这次加的两条，队友那套没有）

| 命令 | 用途 |
|---|---|
| `--selftest` | 30 项协议层断言：CRC 标准向量、组帧、**逐字节投喂**、垃圾前缀重同步、坏 CRC、坏帧尾、两帧连发、参数元数据 73B 回读、通道表对齐（名字/单位/中文/说明四份长度 + 中文宽度不溢出） |
| `--shot-form` | 离屏截图整窗布局（窗口开到屏幕外，不在你桌面上弹），同时打印各分栏的实际尺寸与**通道文字是否被裁**（`chkTxt=225/291`） |
| `--shot-demo` | 先灌 900 帧假遥测 + 10 项假参数，再截图 —— 用来确认波形/滑条真的画得出来 |

后两个还会顺带输出 `crop_bar.png` / `crop_wave.png` / `crop_param.png` 三张 1:1 局部图
（整窗图缩到屏幕宽度后文字全糊，看不出"是裁掉了还是缩小了"）。

## 已踩的坑（改动时注意）

- **分隔条不能在 `Load` 里设**：那时 `SplitContainer` 宽度还没定型，会算出越界值，表现是**参数面板整个消失**。
  所以放在 `OnShown` 里，并且配 `Panel2MinSize` + `FixedPanel`。
- **按钮宽度不要写死**：13.5pt 下"开始接收"四个字就要 123 px，写死 84 设计像素（×1.5=126）
  只剩 3 px 余量，看着就像文字被裁。改用 `AutoSize` + `MinimumSize`。
- **`ChannelStore.Append` 前必须先 `Ensure(N)`**：否则 `count` 被夹成 0，一帧也进不去，波形永远空白。
- **横轴用 PC 本地时间**，不用帧里的 `TS` —— 否则丢包会让波形压缩/拉伸。
- 参数数值框的小数位由**步长**决定（步长 0.001 → 3 位）。所以默认值 `0.1548` 会显示成 `0.155`。
  这是显示精度，不是数据被改；拖动滑条时下发的值也是 3 位小数（对增益来说足够）。
- **心跳默认关**：车端当前是「观测」模型，不需要保活。勾上「心跳 100ms」才会周期性发 PING
  （车端 `HOST_ALIVE_MS=600`，100ms 有 6 倍余量）。将来做接管开车时这个开关必须默认开。
