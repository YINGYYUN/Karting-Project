IMU_Analysis（自研姿态解算）—— 已停用留档
=====================================================================
日期：2026-10-19
状态：**不参与编译、不被任何文件引用**。本文件只记录它曾经怎么工作，
      以及为什么换成队友的 ins_imu。恢复步骤见最后一节。

---------------------------------------------------------------------
一、它原来在哪、干什么
---------------------------------------------------------------------
文件：project/code/IMU_Analysis.c / IMU_Analysis.h（约 2000 行）

运行位置：**CM7_1 核**
  - main_cm7_1.c:  IMU_init()  -> imu963ra_init()（SPI_2 / P15.x）
  - cm7_1_isr.c:   pit0_ch2_isr() 每 10ms 置 IMU_D_and_A_Enable = 1
  - main_cm7_1 主循环：消费该标志 -> IMU_Update_Analysis()
                     -> SHARED_IMU_ADDR->yaw = Yaw_Result * 100（0.01°/LSB）

跨核通道：共享内存 0x280B8000（shared_imu_t）
  - CM7_1 写：SHARED_IMU_WRITE_SYNC()   = SCB_CleanDCache_by_Addr(..., 32)
  - CM7_0 读：SHARED_IMU_READ_SYNC()    = SCB_InvalidateDCache_by_Addr(..., 32)
  - CM7_0 在 pit0_ch0_isr()（10ms）里把 yaw 拷进 Yaw_Receive
  - 同一块内存还传命令：cmd_gyro_calib（0/1/2/3）、cmd_reset

解算方式：DEFINE_IMU_ANALYSIS_MODE = 1
  - 纯三轴陀螺四元数微分积分，dt 硬编码 CYCLE_T = 0.01f
  - 没有加计重力修正、没有磁力计修正 ⇒ yaw 不可观测，静止会匀速漂
  - 输出 atan2f 得到的 ±180°，跨边界会丢整圈

为什么会漂：陀螺零偏在上电标定后冻结，芯片升温会让零偏走 1~2 LSB，
全部被积分进 yaw。没有 ZUPT（静止检测）、没有在线零偏跟踪，就没有任何观测窗口。

---------------------------------------------------------------------
二、为什么换掉
---------------------------------------------------------------------
队友（zjc）的 ins_imu 是同源实现的加强版，三处关键修正：
  1. 陀螺死区 7 LSB(0.49 dps) -> 0.5 LSB(0.035 dps)：不再吃掉 0.5~2 dps 的真实转动
  2. dt 改为 DWT 实测（DWT->CYCCNT），异常值钳回标称周期：改采样率不会再静默错一倍
  3. 额外维护 yaw_acc 累积航向（相邻四元数相对旋转 Z 分量累加），可超 ±360°
另外它还有：Mahony 九轴（加计 + 磁）、ZUPT 静止冻结、在线零偏跟踪、链路坏时不碰 SPI。

---------------------------------------------------------------------
三、现在跑的是什么
---------------------------------------------------------------------
project/code/ins_imu.c / ins_imu.h（移植自 zjc_code/code，仅去掉 ins_odom 的 include
并新增 s_calib_busy 这一个静态量）

运行位置：**CM7_0 核，pit0_ch11_isr（5ms / 200Hz）**，排在 Motor_Crtl_Tick() 之后
  顺序理由：本拍控制律必须先用刚更新的编码器反馈，不能被 IMU 的 SPI 事务推后。
输出：调试页与遥测通道 23 直接调 `ins_imu_get_yaw()`（float，度）。
      ★ 中间那层 `Yaw_Receive`（int16 定点 0.01°/LSB）已一并删除 —— 它当年只是为了跨核共享内存。
跨核共享内存：**已整体撤除**（CM7_1 现在没有业务）。

上电行为变化：
  - main_cm7_0 在 Peripheral_Init() 之后调 ins_imu_init()，**阻塞约 5 秒**做陀螺零偏标定
    （1000 拍 × 5ms；被晃动会重试，最多 5 次 = 25 秒）。屏幕会显示
    "IMU GYRO CALIB... / PLEASE KEEP STILL"。
  - 标定失败不影响开车：ins_imu_update() 走"链路坏"分支，一步都不碰 SPI_2，yaw 恒为 0。
  - 调试页 [IMU] 的"陀螺标定"改成同步调用 ins_imu_calib_gyro()（阻塞约 5 秒），
    "Yaw 归零"改成 ins_imu_zero_yaw()。

四、已知未做（要用航向环之前必须补）
---------------------------------------------------------------------
1. 磁力计标定入口没有接线：ins_imu_mag_calib_start/stop 全工程无调用点，
   而 ins_imu_init() 会把 s_mag_cal_state 清 0 ⇒ 实际一直跑**六轴**。
   要用磁修正需补：触发入口 + off/scale 写 Flash + 上电读回后直接置 state=2。
2. yaw 目前只做显示与遥测，没有参与转向控制。
3. ins_odom / ins_route / Pure Pursuit 一概未移植。
